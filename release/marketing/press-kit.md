# Press Kit Draft

## One-line description
Nobody is a cultivation simulation game where narrative generation, NPC decisions, and progression systems evolve from player choices.

## Feature highlights
- Custom JSON script loading and validation
- LLM-assisted random scenario generation with local fallback
- Option-based and free-text action input
- Intelligent NPC behavior with memory and relationship updates
- Save/load with isolated multi-slot support
- Event log to novel generation and TXT export
