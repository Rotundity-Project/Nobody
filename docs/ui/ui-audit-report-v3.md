# UI 审计报告（V3）

## 1. 范围

本报告覆盖：

- `MainMenu`
- `ScriptSelector`
- `GameRuntimeView`（原 `GameView` 主体验）
- 右侧信息抽屉与系统中心

## 2. 主要结论

1. 主循环（阅读 -> 交互 -> 反馈）已建立清晰主路径。
2. 页面容器拆分与 composables 分层已落地，结构可维护性提升。
3. 系统入口从分散按钮收敛为系统中心，认知负担下降。
4. 仍需持续治理历史文档乱码与术语一致性。

## 3. 改进项（已完成）

- 剧情阅读区排版与段落节奏优化
- 交互区统一容器（选项/自由输入/继续推进）
- 状态快照常驻（角色、章节、位置）
- 信息面板抽屉化（地图/复盘/导出/系统）
- 通知中心（Banner + Toast）
- 键盘可达性与焦点可见性增强

## 4. 风险与建议

- 风险：快照对模板空白过敏导致 CI 波动
  - 建议：快照比较前做 HTML 空白归一化（已实现）
- 风险：文档编码被 PowerShell 误写导致乱码
  - 建议：保持 BOM 策略 + 检查脚本（已实现）

## 5. 验收建议

- 核心路径冒烟：新游戏 -> 推进 -> 保存/加载
- 构建与全量测试必须通过
- 视觉快照变更需人工确认
