# UI 文案规范与术语表（V3）

## 1. 目标

- 保持文案一致、可读、可操作。
- 避免重复表达与术语歧义。

## 2. 术语基线

- 章节
- 剧情推进
- 自动推进
- 等待选项
- 等待自由输入
- 一致性风险分
- 地图行程
- 战斗复盘
- 系统中心

## 3. 文案风格

- 句式尽量短，避免过度文学化提示。
- 错误信息应给出可执行下一步。
- 按钮优先动词开头（如“保存”“读取”“继续”）。

## 4. 错误分级模板

### 阻断错误（Error）

- 标题：操作失败
- 模板：`{动作}失败：{原因}。建议：{下一步}`

### 可恢复错误（Warning）

- 标题：已回退
- 模板：`检测到{问题}，系统已回退到安全路径。`

### 普通提示（Info）

- 标题：系统提示
- 模板：`当前状态：{状态描述}`

## 5. 编码要求

- 文档统一 UTF-8（建议 BOM）
- 提交前运行：
  - `npm run specs:check-encoding`
