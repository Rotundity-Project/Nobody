# UI 文案规范与术语表 v1（V3 A3）

## 目标
- 统一前端术语、状态提示和按钮文案。
- 消除中文乱码与混杂表达，提升沉浸感与可读性。

## 编码规范
- 所有前端源码与文档统一使用 `UTF-8`。
- 禁止混用 GBK/ANSI 文本直接写入 `.vue/.ts/.md`。
- 文案提交前执行一次乱码巡检（关键词示例：`鏃`、`鍓`、`绯`）。

## 术语表（统一写法）
- 章节：`章节`（不用“章回/篇章”混称）
- 剧情推进：`推进剧情`
- 交互状态：
  - `自动推进中`
  - `等待选择`
  - `等待输入`
  - `冷却中`
- 一致性策略：`一致性策略`
- 一致性风险分：`一致性风险分`
- 战斗解释：`战斗解释`
- 关系网络：`关系网络`
- 地图行程：`地图行程`
- 可达节点：`可达节点`
- 不可达节点：`暂不可达`
- 导出经历：`经历导出`
- 系统中心：`系统中心`

## 文案风格
- 句式：短句优先，避免术语堆叠。
- 语气：中性、明确、可执行。
- 主按钮：动词开头（如“开始游戏”“保存进度”“继续推进”）。
- 次按钮：结果导向（如“关闭面板”“返回上一步”）。

## 状态与错误分级模板
- 阻断错误（Error）：
  - 标题：`操作失败`
  - 模板：`{动作}失败：{原因}。请{下一步建议}。`
- 可恢复错误（Warning）：
  - 标题：`已回退到安全状态`
  - 模板：`检测到{风险}，系统已自动回退。你可以{建议动作}。`
- 提示信息（Info）：
  - 标题：`系统提示`
  - 模板：`当前为{状态}。{可选动作说明}。`

## 关键按钮文案基线
- 主菜单：`新游戏` / `继续游戏` / `设置` / `退出`
- 剧本选择：`选择剧本类型` / `开始导入` / `重新选择` / `返回`
- 游戏主界面：`继续推进` / `提交输入` / `保存` / `读取` / `信息面板`
- 系统设置：`保存设置` / `恢复默认` / `关闭`

## 实施建议
- 先替换高频面板：`InfoTabsDialog`、`QuickActionsBar`、`GameTopBar`。
- 建立统一文案常量层（后续可抽至 `shared/copy`）。
- 每次 UI 改动附带文案一致性检查。
