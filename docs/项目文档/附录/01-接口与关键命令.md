# 接口与关键命令

## 1. 前端脚本

### 开发与构建

- `npm run dev`
- `npm run tauri:dev`
- `npm run build`
- `npm run tauri:build`

### 测试

- `npm run test`
- `npm run test:web-core`
- `npm run test:smoke`

## 2. 后端重点命令能力

`tauri_commands.rs` 当前暴露了大量命令，和当前开发最相关的是：

### 游戏状态

- `get_game_state`
- `get_plot_state`
- `save_game`
- `load_game`
- `load_script`

### NoName

- `get_noname_recent_traces`
- `clear_noname_recent_traces`
- `get_noname_mode`
- `set_noname_mode`
- `mark_noname_controlled_output_review`
- `resolve_noname_second_guardrail`
- `apply_noname_manual_plot_text_hint`
- `apply_noname_reviewed_output`

## 3. 命令层维护建议

- 命令函数尽量只负责参数接收、错误转换和返回结果
- 复杂业务逻辑优先下沉到独立模块
- `NoName` 相关命令新增前，先确认是否可以复用已有 apply/review 服务
