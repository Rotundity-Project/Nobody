## 1. 这套文档解决什么问题

这套文档用于替代原来分散在 `docs/architecture`、`docs/qa`、`docs/release`、`docs/ui` 下的旧文档，目标是：

- 用一套中文文档准确描述当前 `main` 分支的真实状态
- 明确 `Nobody` 与 `NoName` 的当前架构、边界和限制
- 给出后续开发方向、优先级和协作方式
- 提供开发、测试、发布的统一入口
