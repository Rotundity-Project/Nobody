# 测试与验证

## 1. 当前验证基线

当前项目至少应维持以下验证能力：

- 后端 `NoName` 定向测试可通过
- 前端 Web mock / store / debug console 定向测试可通过
- 前端构建可通过

## 2. 推荐命令

### 后端

```bash
cargo test noname_ -- --nocapture
```

工作目录：`src-tauri/`

### 前端核心

```bash
npm run test:web-core
```

### 前端 NoName 定向

```bash
npm run test -- --run src/platform/webRuntime.test.ts src/stores/__tests__/gameStore.test.ts src/components/__tests__/AgentTracePanel.test.ts src/components/__tests__/NoNameDebugConsole.test.ts
```

### 构建验证

```bash
npm run build
```

## 3. 当前已知问题

### `.review/` 污染测试发现

如果仓库根目录中存在 `.review/` 工作树，Vitest 会把其中的测试文件也当作当前仓库测试一起执行。

处理建议：

- 不再需要时清理 `.review/`
- 或在测试配置中显式排除 `.review/`

## 4. 回归建议

### 修改 `NoName` 主链时

至少跑：

- `cargo test noname_ -- --nocapture`
- `npm run test -- --run src/platform/webRuntime.test.ts src/stores/__tests__/gameStore.test.ts`

### 修改前端调试界面时

至少跑：

- `npm run test -- --run src/components/__tests__/AgentTracePanel.test.ts src/components/__tests__/NoNameDebugConsole.test.ts`

### 修改运行与发布路径时

至少跑：

- `npm run build`

## 5. 验证策略

- 小改动跑最小相关集
- 主链改动跑后端定向 + 前端定向
- 发布前跑构建验证并补手工主路径检查
