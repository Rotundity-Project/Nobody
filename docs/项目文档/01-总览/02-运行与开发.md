# 运行与开发

## 1. 环境要求

- `Node.js 20+`
- `npm`
- `Rust 1.70+`
- `Tauri 2` 运行环境

## 2. 常用命令

### 安装依赖

```bash
npm install
```

### 前端开发

```bash
npm run dev
```

### Tauri 联调

```bash
npm run tauri:dev
```

### 前端构建

```bash
npm run build
```

### Tauri 构建

```bash
npm run tauri:build
```

## 3. 常用测试命令

### 后端 NoName 定向

```bash
cargo test noname_ -- --nocapture
```

工作目录：`src-tauri/`

### 前端 Web mock / store / debug console 定向

```bash
npm run test -- --run src/platform/webRuntime.test.ts src/stores/__tests__/gameStore.test.ts src/components/__tests__/AgentTracePanel.test.ts src/components/__tests__/NoNameDebugConsole.test.ts
```

### 前端最小核心烟测

```bash
npm run test:web-core
```

## 4. 当前开发建议

- 任何涉及 `NoName` 主线的修改，先看 [NoName 代理系统](../02-架构/02-NoName-代理系统.md)
- 任何涉及任务取舍与优先级，先看 [后续路线图](../03-规划/02-后续路线图.md)
- 任何涉及协作分工，先看 [协作任务清单](../03-规划/03-协作任务清单.md)

## 5. 当前已知注意事项

- 仓库根目录下若存在 `.review/` 工作树，会污染 Vitest 的测试发现范围
- `tauri_commands.rs` 仍然较大，修改前应优先确认是否可以在独立模块中完成
- `.kiro/` 中有大量历史资料，仅供追溯，不应直接当作当前设计基线
