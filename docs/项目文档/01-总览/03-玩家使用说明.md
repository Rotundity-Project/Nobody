# 玩家使用说明

## 1. 游戏主循环

玩家在 `Nobody` 中的主要体验流程是：

1. 阅读当前剧情段落
2. 选择预设选项或输入自由行动
3. 让引擎推进剧情并返回结果
4. 在信息中心查看世界、关系、战斗和系统信息

## 2. 主要界面

### 主游戏界面

- 显示剧情正文
- 显示可选行动
- 支持自由输入

### 信息中心

- 地图与地点
- 角色与关系
- 战斗复盘
- `NoName` 调试信息

### 系统中心

- LLM 配置
- 剧情策略
- 一致性策略
- `NoName` 模式切换

## 3. 存档与加载

- 支持多槽位保存与加载
- 在切换剧本、做大改动或试验新配置前，建议先存档

## 4. 开发模式提示

在开发模式下，项目会额外开放：

- `NoName` 调试台
- Trace 历史查看
- Controlled output review 与人工 apply 流程

这些入口主要面向开发和调试，不是普通玩家的常规操作面。
