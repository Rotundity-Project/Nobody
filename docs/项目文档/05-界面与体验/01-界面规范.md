# 界面规范

## 1. 界面目标

`Nobody` 的界面应服务于两个目标：

- 普通玩家能稳定完成游玩主路径
- 开发者能在不干扰主体验的前提下查看调试信息

## 2. 当前界面分层

### 面向玩家

- 主游戏界面
- 信息中心
- 系统中心
- 存档与加载

### 面向开发

- `NoName` 调试台
- trace 面板
- mode 切换与 review/apply 操作

## 3. 设计要求

- 正常游玩信息与开发调试信息必须分层展示
- `NoName` 的 trace、review、apply 信息要可读，但不能压过主剧情内容
- 同一条 trace 的 proposal、review、guardrail、apply 顺序必须可追踪

## 4. 当前建议

- 优先提升 `NoName` 调试信息的结构化阅读体验
- 在保证现有视觉语言连续的前提下，继续优化信息中心的可扫读性
- 任何 UI 变更都应兼顾桌面窗口场景和调试密度
