# Nobody V2 发布说明（正式）

发布日期：2026-02-19  
版本：1.1.0

## 核心更新

- 剧情与一致性：
  - 引入一致性校验器 V2，支持重复检测、跨章对齐、章节目标补锚、等待态兜底。
  - 新增叙事厚度约束：节奏阶段提示（铺垫/冲突/转折/回落）、叙事覆盖度检测与空洞表达重生成。
- 角色与成长：
  - 角色档案重构：新增功法树、装备栏、战斗倾向字段。
  - 成长轨迹补齐：突破、反噬、顿悟、战斗倾向变化均写入成长日志。
- 功法与战斗：
  - 功法语义画像接入战斗链路（类型/特性/门槛/风险）。
  - 战斗硬约束裁决接入（大境界压制、武器条件、倾向冲突）。
- 地图与行程：
  - 地图总览补充区域生态画像（环境标签、资源标签、控制势力、事件热区）。
  - 行程改为按路径步数计时，支持分段行进建议。

## 质量门禁结果

- 前端：`npm test` 通过（14 文件 / 42 用例）。
- 后端：`cargo test -q` 通过（286 passed / 0 failed / 2 ignored）。
- 静态检查：`cargo clippy -- -D warnings` 通过。

## 兼容性与迁移

- 存档策略：沿用增强 JSON 存档。
- 兼容结论：`1.x` 旧存档可通过迁移链路加载并继续游玩。
- 迁移参考：`docs/release/migration-v2.md`。

## 已知限制

- 性能基准（P95）仍按手动流程执行，建议在灰度阶段持续采样。
- 发布阶段仍建议保留灰度观察窗口（72 小时）。

## 发布建议

1. 内部测试包验证通过后，先进行 10%-20% 灰度。  
2. 灰度阶段重点观测一致性风险分、存档迁移成功率与运行耗时分位数。  
3. 72 小时稳定后执行全量发布。
