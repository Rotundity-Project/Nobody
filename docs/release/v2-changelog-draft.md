# Nobody v1.1.0 (V2) 变更日志草案

发布日期: TBD  
当前状态: Draft

## Highlights

- 新增结构化实体管线（Schema 校验 + 规则裁决 + 持久化索引）
- 新增分层记忆与上下文构建器（短/中/长期记忆协同）
- 新增数值守门系统（区间约束、归一化、拒收策略）
- 剧情推进链路增强（显式交互态、读档恢复对齐、一致性修复）
- 小说导出升级（章节目录、事实覆盖率与追溯能力）

## Quality & Performance

- 属性测试扩展:
  - 章节目录完整性
  - 导出事实覆盖率（含句子级）
  - 地图位置一致性（含 save-load-plot 恢复链路）
  - 功法风险标签导出追溯
- 性能基线:
  - Rust 引擎基准支持批量采样 `P50/P95/P99`
  - 新增耗时诊断聚合命令
  - 新增手动性能工作流 `.github/workflows/perf-benchmark.yml`

## Migration

- 新增存档字段:
  - `schema_version`
  - `migration_history`
- 旧存档兼容:
  - 缺失新字段的 `1.x` 存档可加载并迁移到 `v2_0` 运行态

## Known Limitations

- 章节目标驱动尚未形成“失败即重生成”闭环。
- 地图与行程 UI 仍在规划实现中。
- 战斗结果解释器尚未结构化输出主导/反转因子。
