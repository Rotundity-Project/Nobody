# V2 发布准备说明（草案）

更新时间: 2026-02-19
建议版本: `1.0.0 -> 1.1.0`

## 变更摘要

- 剧情推进增强:
  - 引入显式 `interaction_state` 状态机，降低无输入卡死概率。
  - 增强章节目标弱命中时的自动修复锚点。
- 存档兼容增强:
  - 新增 `schema_version` 与 `migration_history` 字段。
  - 旧存档加载时执行轻量迁移（内存态，不覆盖原文件）。
- 导出与回归增强:
  - 章节目录完整性属性测试。
  - 导出事实覆盖率属性测试（source_event_ids 完整覆盖）。

## 迁移说明

- 新增字段:
  - `SaveData.schema_version`（默认 `v2_0`）
  - `SaveData.migration_history`（记录迁移步骤）
- 兼容策略:
  - 缺失新字段的旧档可加载。
  - 旧档交互态会按 `is_waiting_for_input + available_options` 归一化。

## 存档兼容说明

- 支持版本: `1.x`
- 拒绝加载: `2.x+`（当前未开放）
- 迁移失败策略:
  - 保留原文件不覆盖。
  - 返回明确错误信息。

## 已知限制

- 章节目标驱动目前为“强制补锚点修复”，尚未接入“LLM 重生成闭环”。
- 性能指标（P95）尚未产出正式基准报告。
- 地图/功法相关不变量测试仍待扩展。

## 灰度建议

1. 内部包回归（存档读写/剧情推进/导出）。
2. 小范围灰度（10%-20% 用户）。
3. 观察 72 小时错误日志后再全量发布。

## 回滚方案

- 版本回滚到 `1.0.0`。
- 对异常存档优先走只读加载与导出保底。
- 保留迁移日志用于问题定位。
