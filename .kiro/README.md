# .kiro 本地工作区说明

`.kiro/` 用于保存本地工作资料，不是正式产品文档目录。

## 主要用途

- 当前阶段规格与实施计划
- 历史草稿与归档
- 会话交接记录
- 本地参考笔记

## 与 `docs/` 的区别

- `docs/`：正式文档，适合长期保留与团队协作
- `.kiro/`：本地工作区，适合规划、草稿、handoff、设计演进记录

## Nobody 入口

请查看：

- `.kiro/specs/Nobody/README.md`

## 使用规则

- 新想法、新草稿、新 handoff 优先写入 `.kiro/`
- 稳定、可复用、适合长期保留的内容，再整理迁移到 `docs/`
- 不要让运行时代码直接依赖 `.kiro/` 下的内容
